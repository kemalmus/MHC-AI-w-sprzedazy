# Fallbacki dla trenera

Ten folder zawiera przykładowe odpowiedzi do ujawnienia po pierwszej próbie uczestników oraz storyboard na wypadek braku narzędzia video.

## Zawartość

- `golden_briefing.md` - możliwy briefing przed spotkaniem z BudMax.
- `golden_internal_summary.md` - przykład podsumowania i rozdzielenia działań po spotkaniu.
- `golden_complaint_analysis.md` - przykład analizy reklamacji na podstawie ograniczonego fragmentu dokumentu.
- `golden_sales_lab_angle.md` - jedna hipoteza angle, skrypt i kierunek wizualny dla Sales Lab.
- `sample_storyboard.pdf` - sześć neutralnych kadrów wektorowych do użycia, gdy video nie jest dostępne.

## Jak prowadzić z tymi materiałami

Traktuj pliki jako przykłady do rozmowy, a nie odpowiedzi jedyne słuszne. Nie pokazuj ich przed pierwszą próbą uczestników. Przy porównaniu prac wracaj do danych źródłowych, jawnych założeń, brakujących informacji i decyzji, które nadal wymagają człowieka.

Wszystkie nazwy, scenariusze i materiały case'u są fikcyjne i szkoleniowe. Storyboard nie przedstawia realnych osób, marki ani rzeczywistej oferty.

## Podmiana storyboardu lub video

Storyboard jest zapisany jako `sample_storyboard.pdf` z neutralnymi ilustracjami wektorowymi, więc nie wymaga plików zdjęciowych. Aby go podmienić, zastąp ten PDF innym sześciokadrowym storyboardem lub zatwierdzonym materiałem video i zachowaj tę samą ścieżkę pliku, jeśli strona odwołuje się do niej.

Jeśli podczas szkolenia nie ma generatora video, użyj sześciu kadrów jako planu ujęć. Zespół może odczytać skrypt, omówić kolejność plansz, zebrać krytykę i poprawić jedną rzecz.
