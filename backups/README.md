# Kopia strony sprzed przebudowy M365

`budmax-before-m365-2026-11-04.zip` zawiera stan wszystkich plików projektu sprzed przebudowy: stronę, treści, materiały, dokumentację i konfigurację publikacji, wraz z niezacommitowanymi zmianami. Nie zawiera historii `.git` ani wyników ankiety z katalogu Downloads.

Archiwum ma plik `BACKUP_MANIFEST.json` z listą plików i sumami SHA-256. Sprawdzono integralność ZIP i zgodność każdej sumy.

Aby obejrzeć poprzednią wersję, rozpakuj archiwum do osobnego katalogu i uruchom tam `python3 -m http.server 8001`. Otwórz `http://localhost:8001`. Poprzednia wersja używa zapisu przeglądarki `mhc-ai-sales-training-v2`, nowa `v3`.

Przy przywracaniu do głównego katalogu najpierw zabezpiecz aktualną wersję. Nie rozpakowuj archiwum na bieżące pliki tylko po to, aby porównać wersje.
